# 课程视频 HLS 上线与后续治理记录

## 本期实现边界

- 新上传课程视频仅接收 MP4、MOV，单文件最大 500 MB。
- 浏览器使用受限上传凭证直传七牛，服务端提交异步 `adapt/m3u8` 任务。
- 输出 360p、480p、720p 三档自适应 HLS，分片时长默认 6 秒。
- 转码状态为 `READY` 后才允许关联章节；`PROCESSING`、`FAILED` 均不能保存为章节视频。
- 存量直链视频继续兼容播放，不自动批量转码，避免未经确认产生七牛转码费用。

## 上线步骤

1. 执行 `yub-edu/DB/DDL/20260916_video_hls_transcode.sql`。
2. 在环境变量或配置中心提供 `QINIU_ACCESS_KEY`、`QINIU_SECRET_KEY`、`QINIU_BUCKET`、`QINIU_DOMAIN`；可选配置独立转码队列 `QINIU_TRANSCODE_PIPELINE`。
3. 七牛侧启用数据处理能力，并确认绑定的公有 CDN 域名可访问 `.m3u8`、`.ts`（或七牛实际生成的分片格式）。
4. CDN 跨域规则允许学习站点来源访问 HLS 文件，并允许 `GET`、`HEAD`、`Range` 请求；生产站点和 CDN 均应使用 HTTPS，避免混合内容被浏览器拦截。
5. 发布后用弱网模式验证：章节快速连续切换、转码失败、播放中断网再恢复、拖动进度条、刷新 `/h5/pages/course/study?...`。

## 章节树检查

学习页接口 `GET /student/chapter/list?cid={courseId}` 返回递归的 `children` 字段；前端只对叶子节点发起章节详情和视频加载，父节点仅负责展开/收起。若页面仍显示为扁平列表，先在 Network 中检查响应：

```json
{"list":[{"id":1,"chapterName":"第一章","children":[{"id":2,"chapterName":"第一节","children":[]}]}]}
```

如果响应中所有节点的 `children` 都为空，说明数据本身没有建立父子关系，应只读检查 `edu_chapter.parent_id`，再通过章节管理功能修正归属；不要根据章节名称在前端猜测层级。

如果日志出现 `Unknown column 'asset_id' in 'field list'`，说明后端版本已经更新但数据库迁移未执行。此时应先在目标库确认：

```sql
SHOW COLUMNS FROM edu_chapter_video LIKE 'asset_id';
SHOW TABLES LIKE 'edu_video_asset';
```

确认当前连接的是应用实际使用的数据库后，再完整执行上述 DDL，最后重启应用并重新请求章节详情。不要只手工补一列：新上传链路还需要 `edu_video_asset` 表保存七牛转码任务和 HLS 播放地址。

## 回滚

- 前端回滚不删除七牛源文件或 HLS 产物。
- 数据库新增列 `edu_chapter_video.asset_id` 可为空，旧版本仍可读取原有 `video_url`。
- 若暂停新链路，先下线管理端新上传入口，再回滚服务；不要直接删除 `edu_video_asset`，该表保留转码任务审计信息。

## 已登记安全债务：公有 CDN 播放地址

当前按本期决定采用公有 CDN。课程详情接口仍校验登录、购买或免费试看权限，但一旦用户取得真实 `.m3u8` 地址，地址本身不再校验课程权限，可能被复制分享并绕过业务鉴权。

后续修复建议按优先级执行：

1. 将课程视频迁移到私有空间，播放前由业务服务校验课程权限并签发短时播放凭证。
2. 对 HLS 主清单和所有分片统一采用可续签的短时鉴权，避免只保护 `.m3u8` 而分片仍可直接访问。
3. 配置 CDN 防盗链、HTTPS、合理缓存和限速；防盗链只能作为补充，不能替代业务鉴权。
4. 播放器在凭证即将过期时无感续签，兼顾长视频连续播放。
5. 增加异常播放审计（账号、课程、IP、设备、流量），建立分享和盗刷告警。

## 存量视频迁移

本期不自动触发。后续应由管理端提供“选中资源后转码”的人工操作，展示预计数量/费用，成功后事务性替换章节关联；失败时保留原直链并可重试，不做不可逆批量覆盖。
